### Deviation from the brief

The brief puts the picker metadata (tag, name, biome pool) in `src/enemies/mid/<kind>.ts`. That can't work with those modules staying pure: `midpick`, `runsave` and `warmplan` read it at load, and a kind's file imports the sim and, through `core.ts`, the DOM. One ES module can't be both. So the metadata is one row in `roster.ts`. **Adding a held biome kind is still one new file per side plus one line.** Both folders load by glob, so the row is the only shared line, and the render side needs none.
